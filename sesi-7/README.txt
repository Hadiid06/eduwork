TUGAS SESI 7 - DASAR PHP

Isi:
1. tugas1_dasar_php.php   : variabel, operator, if-elseif-else
2. tugas2_form_input.php  : form input nama, harga, deskripsi
3. tugas3_validasi.php    : menerima POST dan memvalidasi input

Cara menjalankan dengan XAMPP:
1. Ekstrak folder ini ke C:\xampp\htdocs\tugas_dasar_php_sesi7
2. Jalankan Apache dari XAMPP Control Panel.
3. Buka http://localhost/tugas_dasar_php_sesi7/tugas1_dasar_php.php
4. Klik tautan Tugas 2, lalu kirim form untuk mencoba validasi.

Catatan:
Versi ini belum menyimpan data ke database. Validasi dilakukan di PHP meskipun form juga memakai atribut required, karena validasi browser dapat dilewati.
